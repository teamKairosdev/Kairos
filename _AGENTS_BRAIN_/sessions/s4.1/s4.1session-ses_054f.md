## 3. 3개 병렬 감사 결과 — 발견된 마이너 이슈 7건

### 이슈 A: llmCache alias 누락 (MEDIUM)
- **파일**: `nuxt.config.ts` (`nitro.alias`)
- **내용**: `llmCache`가 alias 목록에서 빠짐. 빌드 시 외부 의존성 경고 발생.
- **조치**: alias 추가 필요.

### 이슈 B: Vercel rewrites가 Nitro 자동 라우팅과 충돌 가능 (LOW)
- **파일**: `vercel.json` (lines 24-26)
- **내용**: 수동 `rewrites` 규칙이 Nuxt/Nitro의 자동 생성 Vercel 구성을 덮어씀.
- **조치**: `rewrites` 블록 제거 권장. Nuxt `routeRules`로 이미 SPA fallback 처리됨.

### 이슈 C: 캐시가 읽기 전용 (MEDIUM)
- **파일**: `server/api/llm/refine.post.ts`
- **내용**: `getCachedResponse`로 읽기만 하고 `setCachedResponse`로 쓰지는 않음. = 캐시가 사실상 무효.
- **조치**: 응답 저장 로직 추가.

### 이슈 D: 불필요한 import 3건 (LOW)
- **파일**: `server/api/llm/chat.post.ts` — `getCachedResponse`, `setCachedResponse` import만 있고 미사용
- **파일**: `server/api/interviews/[id]/chat.post.ts` — `asc` import만 있고 미사용
- **조치**: import 제거.

### 이슈 E: `invalidateCache` 데드 파라미터 (LOW)
- **파일**: `server/services/llmCache.ts`
- **내용**: `invalidateCache(pattern: string)`에서 `pattern` 파라미터가 내부에서 전혀 사용되지 않음. 항상 전체 키 삭제.
- **조치**: 파라미터 제거 또는 함수 본문 구현.

### 이슈 F: `.env.example`에 `GOOGLE_API_KEY` 누락 (LOW)
- **파일**: `.env.example`
- **내용**: `nuxt.config.ts`에서 `GOOGLE_GENERATIVE_AI_API_KEY || GOOGLE_API_KEY` 폴백을 지원하지만, `.env.example`에는 `GOOGLE_API_KEY`가 문서화 안 됨.
- **조치**: 주석 라인 추가.

### 이슈 G: `JWT_SECRET`이 더 이상 사용되지 않음 (LOW)
- **파일**: `.env.example`, `docker-compose.yml`
- **내용**: Better Auth로 완전 전환되어 `JWT_SECRET` env var를 아무 코드도 읽지 않음. 하지만 문서와 docker-compose에 잔존.
- **조치**: 제거하거나 "미사용" 주석 추가.

## 5. 프로덕션 갭 (Production Roadmap)

현재 상태: **"기술 검증이 끝난 데모/프로토타입"**

실서비스 배포를 위해 필요한 10대 과제:

### P1. 테스트 코드 (0% → 필요)
- 단위 테스트: `vitest` + Vue Test Utils
- E2E 테스트: `playwright` 또는 `cypress`
- AI 응답 Mock: `vitest-fetch-mock` + AI SDK 테스트 유틸

### P2. 모니터링/로깅
- `@ai-sdk/otel` 활성화 (현재 설치만 됨, 미연동)
- OpenTelemetry exporter 설정 (console → production exporter)
- 에러 추적: Sentry 또는 Highlight.io

### P3. CI/CD 파이프라인
- GitHub Actions: `lint → typecheck → test → build → deploy`
- Vercel Preview Deployments (PR당 자동 프리뷰)

### P4. OAuth 인증
- Better Auth는 OAuth를 기본 지원함 (`better-auth/providers`)
- Google, Kakao, GitHub OAuth 연동
- 로그인 페이지 UI 개선 (소셜 로그인 버튼)

### P5. SEO
- 공개 라우트 (`/`)만 `prerender: true`, 나머지 `ssr: false`
- 블로그/랜딩 페이지 추가 시 `hybrid` 렌더링 고려
- 메타 태그 동적 생성

### P6. 에러 핸들링
- `alert()` → `useToast()` (Nuxt UI v4의 `UToast`)
- 전역 에러 바운더리 (`error.vue`)
- API 에러 통합 포맷

### P7. 접근성 (a11y)
- `aria-*` 속성 감사
- 키보드 네비게이션 검증
- 색 대비(contrast) 검증

### P8. 국제화 (i18n)
- `@nuxtjs/i18n` 모듈 도입
- 한국어/영어 전환
- 모든 하드코딩 문자열 추출

### P9. 비용 최적화 튜닝
- Anthropic 캐시 히트율 모니터링
- 모델 라우팅 임계값 실제 사용량 기반 조정
- Cloudflare Workers AI (오픈소스 모델) 폴백 도입 검토

### P10. 성능 최적화
- LCP/FCP/TTFB 측정 (Lighthouse)
- 청크 분할 최적화 (1.25MB pdf.worker.min 분할)
- 이미지 최적화
- 번들 분석 (`nuxt analyze`)

## 6. 기술 아키텍처 개요

```
[브라우저 SPA] ←→ [Vercel Serverless (Nitro)]
    ├── 클라이언트 AI: @huggingface/transformers (임베딩/분류)
    ├── 문서 파싱: pdfjs-dist + mammoth
    ├── 로컬 벡터: vectra/browser + IndexedDB
    ├── 로컬 LLM: @mlc-ai/web-llm (선택)
    └── PWA: 서비스워커 + 오프라인 큐 + IndexedDB 채팅

[서버 (Nitro)]
    ├── Better Auth (HttpOnly 쿠키, Drizzle Adapter)
    ├── AI SDK v7 + model routing
    ├── Upstash Redis (Rate Limit + Semantic Cache)
    └── Neon PostgreSQL + pgvector

[의존성]

    nuxt/ui 4 | Tailwind CSS 4
    drizzle-orm 0.45 | drizzle-kit 0.31

    @upstash/ratelimit 2.0 | @upstash/redis 1.38
    @huggingface/transformers 4.2 | vectra 0.15

    idb 8.0
```
