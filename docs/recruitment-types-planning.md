# 지원자 유형별 면접 전략 기획서

> 2026-07-29 기준. 기존 Kairos 플랫폼 위에 고졸전형 / 대졸전형 / 경력자전형을 통합하는 설계.

## 1. 지원자 유형별 시나리오 상세화

### 1.1 고졸전형 (High School Graduate Track)

**대상**: 고등학교 졸업 예정자 / 기졸업자. 실무 진입 초기 단계.

| 항목 | 내용 |
|------|------|
| **면접 스타일** | 인성 중심 + 직무 적합도 + 성장 가능성 |
| **질문 유형** | - 지원 동기 및 회사 인지도<br>- 학교 생활 / 동아리 / 봉사 활동<br>- 기본적인 직업 윤리 및 태도<br>- 간단한 상황 대처 능력 (역량 기반) |
| **AI 평가 기준** | - 의사소통 명확성 (30%)<br>- 성실성/책임감 태도 (30%)<br>- 논리적 사고력 (20%)<br>- 성장 가능성 (20%) |
| **난이도 옵션** | `beginner` — 기본 인성 위주, `standard` — 상황 대처 포함 |
| **ATS 연계** | 학력/자격증 위주 매칭, 경력 점수는 낮게 반영 |

**시나리오 흐름**:
```
1. 고졸전형 선택 → 2. 직무 선택 (생산/서비스/사무보조 등)
→ 3. AI 면접 시작 (기본 인성 질문 5~7개)
→ 4. 상황 대처 질문 2~3개 (STAR 라이트 버전)
→ 5. 종합 평가 및 피드백 리포트
→ 6. (선택) 기업 매칭 리스트 제공
```

### 1.2 대졸전형 (University Graduate Track)

**대상**: 대학(원) 졸업 예정자 / 기졸업자. 전공 지습 + 실무 경험(인턴/프로젝트) 있음.

| 항목 | 내용 |
|------|------|
| **면접 스타일** | 전공 지식 + 인성 + 직무 적합도 |
| **질문 유형** | - 전공 기초/심층 지식 질문<br>- 학부 프로젝트 / 졸업 작품 관련<br>- 인턴십 경험 기반 행동 질문<br>- 직무 관련 트렌드/산업 이해도<br>- 조직 적응력 및 협업 태도 |
| **AI 평가 기준** | - 전공 지식 이해도 (30%)<br>- 프로젝트 경험의 질 (25%)<br>- 문제 해결 능력 (25%)<br>- 커뮤니케이션 및 태도 (20%) |
| **난이도 옵션** | `junior` — 기초 전공 + 인성, `medium` — 심화 전공 + 프로젝트 |
| **ATS 연계** | 전공 일치도, 학점, 자격증, 인턴 경험 매칭 |

**시나리오 흐름**:
```
1. 대졸전형 선택 → 2. 계열/전공 선택 (인문/이공/상경/예체능)
→ 3. 세부 직무 선택 → 4. AI 면접 시작
→ 5. 전공 지식 질문 3~4개 → 6. 프로젝트 경험 질문 2~3개
→ 7. 인성/조직 적합도 질문 2~3개
→ 8. 종합 평가 + ATS 분석 리포트
→ 9. 취약점 보강용 Q&A 플래시카드 자동 생성
```

### 1.3 경력자 전용 (Experienced Track)

**대상**: 경력 3년 이상 이직 희망자. 포트폴리오 보유.

| 항목 | 내용 |
|------|------|
| **면접 스타일** | 기술 심층 + 리더십 + 전략적 사고 |
| **질문 유형** | - 아키텍처 설계 및 기술 의사결정<br>- 대규모 프로젝트 경험 및 성과<br>- 리더십 / 갈등 관리 / 멘토링 경험<br>- 비즈니스 임팩트 및 KPI 달성<br>- 최신 기술 트렌드 식견<br>- (선택) 라이브 코딩 / 시스템 설계 |
| **AI 평가 기준** | - 기술 깊이 및 설계 능력 (30%)<br>- 프로젝트 성과의 정량적 임팩트 (25%)<br>- 리더십 및 협업 능력 (20%)<br>- 전략적 사고 및 의사결정 (25%) |
| **난이도 옵션** | `senior` — 기술 리더십 중심, `expert` — CTO/VP 레벨 |
| **ATS 연계** | 경력 연차, 기술 스택, 리더십 경험, 성과 지표 집중 매칭 |

**시나리오 흐름**:
```
1. 경력자전형 선택 → 2. 직무 분야 선택 (개발/디자인/PM/마케팅 등)
→ 3. 경력 연차 입력 → 4. 포트폴리오/프로젝트 이력 등록 (선택)
→ 5. AI 면접 시작 (기술 심층 4~5개)
→ 6. 리더십/전략 질문 2~3개
→ 7. (선택) 라이브 코딩 또는 시스템 설계 과제
→ 8. 종합 평가 + 포트폴리오 기반 피드백
→ 9. 시니어 맞춤 Q&A 세트 생성
```
