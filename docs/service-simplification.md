# 서비스 단순화 및 3×3 솔루션 매트릭스

> 2026-07-29. 모든 취업준비생을 대상으로 하되, **부족한 영역**과 **전형**을 교차 분류하여 9개 맞춤 솔루션 제공.

---

## 1. 핵심 분류 체계

### 1.1 전형 (수직 축)

| 전형 | 대상 |
|------|------|
| **고졸전형** | 고등학교 졸업(예정)자, 실무/인성 중심 |
| **대졸전형** | 대학(원) 졸업(예정)자, 전공+실무 |
| **경력자전형** | 경력 3년↑ 이직 희망자, 기술/리더십 |

### 1.2 부족 영역 (수평 축)

| 부족 영역 | 특징 |
|----------|------|
| **이력서 부족** | 경험은 있으나 문서화 미흡, STAR 부재, 성과 수치 없음 |
| **면접 부족** | 이력서는 괜찮으나 면접 스킬/답변 전략 부재 |
| **종합 부족** | 이력서+면접 모두 준비 필요 |

### 1.3 3×3 솔루션 매트릭스

| | 이력서 부족 | 면접 부족 | 종합 부족 |
|---|---|---|---|
| **고졸전형** | 고졸 기초 이력서 작성 가이드 + STAR 라이트 | 고졸 인성/상황 면접 트레이닝 | 고졸 올인원 취업 부트캠프 |
| **대졸전형** | 전공/프로젝트 기반 이력서 고도화 | 전공 심층+행동 면접 집중 트레이닝 | 대졸 종합 취업 패키지 |
| **경력자전형** | 포트폴리오+정량 성과 중심 이력서 리라이팅 | 기술 심층+리더십 면접 코칭 | 경력자 이직 올인원 솔루션 |

## 2. 서비스 단순화 원칙

### 2.1 핵심 서비스 3개로 압축

```
                ┌─────────────────────┐
                │   내 강점/약점 진단     │ ← 프로필 + AI 간단 진단
                └──────────┬──────────┘
                           ▼
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  이력서 집중   │  │  면접 집중     │  │  종합 올인원  │
│  솔루션      │  │  솔루션      │  │  솔루션      │
│  - 이력서 고도화│  │ - 모의 면접   │  │ - 이력서+면접 │
│  - ATS 분석   │  │ - Q&A 생성   │  │ - ATS+Q&A   │
│  - 휴머나이저  │  │ - 피드백     │  │ - 전체 관리  │
└──────────────┘  └──────────────┘  └──────────────┘
```

### 2.2 기존 서비스 단순 매핑

| 기존 서비스 | 단순화 후 |
|------------|----------|
| 이력서 고도화 체인 (Draft→Evaluate→Improve) | → **이력서 솔루션**에 통합, 1클릭 실행 |
| AI 모의 면접 (SSE) | → **면접 솔루션**에 통합 |
| ATS 분석 | → **이력서 솔루션**의 하위 기능 |
| AI Humanizer | → **이력서 솔루션**의 하위 기능 |
| Q&A 생성 | → **면접 솔루션**의 하위 기능 |
| 경력 포트폴리오 | → **프로필**에 통합 |
| 기업 맞춤 평가 | → **이력서 솔루션**의 선택 기능 |

## 3. 사용자 플로우 (단순화)

```
회원 가입
  ▼
[프로필 설정] ← 전형 + 부족 영역 선택 (또는 AI 추천)
  ▼
┌─────────────────────────────────────────┐
│          맞춤 대시보드                    │
│                                          │
│  "고졸전형 · 이력서 부족" 님을 위한 추천   │
│                                          │
│  📋 [이력서 작성 시작]    🎯 목표 기업 설정 │
│  💡 맞춤 팁: STAR 형식으로 경험을 정리하세요 │
│                                          │
│  진행 상태: 이력서 30% · 면접 0%          │
└──────────────────────────────────────────┘
  ▼
[이력서 솔루션]  or  [면접 솔루션]  or  [종합 올인원]
```

## 4. DB/API 단순화 방향

### 4.1 users 테이블에 진단 필드 추가

```diff
+  applicantType: 'high_school' | 'university' | 'experienced'
+  weaknessType: 'resume' | 'interview' | 'comprehensive'
+  profileCompleted: boolean
```

### 4.2 API 단순화

| 기존 | 단순화 |
|------|--------|
| `/api/resumes/[id]/refine` | → 유지, 1클릭 실행 |
| `/api/interviews` | → 유지, 면접 솔루션에서 호출 |
| `/api/ats`, `/api/humanizer`, `/api/qa` | → 유지하되 내부 라우팅 |
| `/api/companies/evaluate` | → `/api/resumes/[id]/company-eval` 로 이동 |
| `/api/companies` (목록) | → 유지, 목표 기업 선택용 |
