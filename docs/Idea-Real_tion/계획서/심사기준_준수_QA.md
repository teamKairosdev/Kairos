##  먼저: "개인의 대시보드"라는 한마디 — 왜 부족한가?

### Q. 지금 쓰고 있는 한마디 슬로건 "개인의 대시보드"는 적절한가?

**A. 아니다. 세 가지 이유로 명백히 부족하다.**

1. **추상적이다** — "대시보드"는 모든 서비스가 쓸 수 있는 단어다. Google Analytics도 대시보드, Notion도 대시보드, 메일함도 대시보드다. 이 단어만으로는 Kairos가 무엇인지 전혀 알 수 없다.

2. **Kairos가 해결하는 문제가 안 보인다** — 심사 기준 1번(문제 정의, 15점)에서 핵심은 "해결하는 문제가 명확하고 구체적인가"다. "개인의 대시보드"라는 말엔 문제도, 해결책도 없다.

3. **창의성이 전달되지 않는다** — 심사 기준 3번(창의성, 20점)에서 "기존에 없던 것"이 느껴져야 한다. "대시보드"는 이미 수없이 많다.

### Q. 그렇다면 어떤 한마디가 맞는가?

**A. 다음 후보들을 검토한다. 핵심 조건: ① 문제가 담길 것 ② 독창성이 느껴질 것 ③ 대상(취업준비생)이 바로 공감할 것**

#### 후보 1 (현재 공식 채택 — 전략방향성.md 기준)
> **"커리어의 총체적 추적, 종합적 활용 및 관리를 지원하는 종합 경력개발 에이전트 서비스 플랫폼"**

- [v] 명확하다
- [v] 공식 PPT 2번 슬라이드 기준과 일치
- [x] 너무 길다 — 발표 첫마디로 쓰기엔 무겁다

#### 후보 2 (발표 오프닝용 짧은 버전)
> **"당신의 커리어 전 생애를 기억하고, 분석하고, 대신 행동하는 AI"**

- [v] 짧고 강렬하다
- [v] "기억 + 분석 + 대신 행동" — 커리어 OS + 에이전트가 한번에 표현된다
- [v] 취업준비생이 들으면 바로 "나를 위한 것"이라고 느낀다

#### 후보 3 (더 감성적/브랜딩 버전)
> **"흩어진 나의 커리어를, 결정적 순간에 하나로"**

- [v] 카이로스(결정적 순간)의 어원과 연결된다
- [v] "흩어진"이라는 단어가 Pain Point를 직접 건드린다
- 단독으로 쓰기보단 브랜드 태그라인으로 적합

#### 후보 4 (기능 중심 실용 버전)
> **"이력서·면접·ATS·문서편집·에이전트 — 커리어 전 과정을 하나로"**

- 기능이 열거되어 심사위원이 즉시 파악 가능
- 창의성 어필엔 약함

# 심사 항목 1: 문제 정의 (15점)

## Q1-1. 우리가 정의한 문제는 무엇인가?

**A.**  
"취업 준비생의 커리어 데이터는 흩어져 있고, AI 분석도 일회성이며, 자신의 경험과 지식을 막상 기회가 왔을 때 꺼내 말과 글로 풀어내기 어렵다. 이를 종합적으로 추적하고 관리하고 활용하는 플랫폼이 없다."

## Q1-2. 이 문제 정의가 "명확하고 구체적"한가?

**A. 반만 맞다. 아직 충분히 구체적이지 않다.**

지금 문제 정의의 수준:
- "데이터가 흩어져 있다" — [v] 방향은 맞지만
- "말과 글로 풀어내기 어렵다" — [v] 공감 가능하지만
- **아직 페르소나가 없다** — [x] 누가, 언제, 어디서의 구체성이 부족

심사위원이 원하는 수준 (심사기준.md에 명시):
> "경기도 고등학생 A군은 자소서를 10군데 제출했지만 피드백이 없고 내 위치를 모른다" (O)

## Q1-3. 구체적인 페르소나를 어떻게 정의해야 하는가?

**A. 다음과 같이 구체화하라.**

- 상황: 대기업 SW 직군 3곳, 스타트업 5곳 지원 중
- Pain Point:
  - 이력서 파일이 PC에 8개 버전으로 흩어져 있다
  - 자소서를 쓸 때마다 ChatGPT에 다시 설명해야 한다 (맥락 0)
  - 면접 후 내가 어디서 틀렸는지 아무도 알려주지 않는다
  - 취업 스터디 그룹에서 받은 피드백은 주관적이고 불일치한다

**페르소나 2: 이직 준비 경력자 (B2C 잠재)**

- 상황: 현 직장 다니며 이직 준비
- Pain Point:
  - 5년 동안의 프로젝트, 성과, 기술 성장이 정리된 곳이 없다
  - 포트폴리오를 새로 쓸 때마다 "내가 뭘 했더라" 기억이 안 난다
  - 야근 후 면접 준비할 시간이 없다 → 에이전트가 대신해줬으면

**페르소나 3: 기업 HR 담당자 (B2B 잠재)**

  - 지원자를 객관적으로 비교할 도구가 없다
  - 면접 질문을 매번 새로 만드는 데 시간이 많이 든다

- 기업 입장: ATS 필터링 실패로 좋은 인재 놓치는 비율 감소

## Q2-3. "지속가능성"을 어떻게 설명하는가?

**A. Kairos의 지속가능성 구조:**

```
[데이터 플라이휠]

사용자 이력서 업로드
    ↓
AI 분석 → 피드백 데이터 축적
    ↓
더 많은 사용자 유입 (네트워크 효과)
    ↓
더 많은 데이터 → AI 더 정교해짐
    ↓
경쟁사가 따라오기 어려운 데이터 해자(moat) 형성
```

- 사용량 기반 수익 모델 → 서비스 유지 가능
- B2B 기업 고객 (HR 솔루션) → 안정적 수익원
- 오픈소스 AI 모델 활용 → 비용 절감 지속

## Q3-3. 창의성의 핵심 포인트는 무엇인가?

**A. 3가지 창의성 포인트를 명확히 가져가야 한다.**

**창의성 포인트 1: 패러다임 전환**
- 기존: "AI에게 요청 → 결과 받기" (도구형)
- Kairos: "AI가 내 커리어를 기억하고 스스로 판단" (에이전트형)

**창의성 포인트 2: 융합의 독창성**
- Notion/Obsidian(지식베이스) × Threads/X(SNS) × AI Agent를 **커리어 도메인에서 처음으로 융합**
- 이 3가지를 동시에 하는 서비스는 전 세계에 없다

**창의성 포인트 3: AI의 투명성**
- AI가 무엇을 생각하는지 (thinking 과정)를 실시간으로 보여주는 UI
- 블랙박스 AI가 아닌 "같이 생각하는 파트너"

**Q: "ChatGPT나 Claude로도 할 수 있는 것 아닌가요?"**

A: "세 가지 차별점이 존재합니다.

첫째, **기억의 연속성**입니다. ChatGPT는 개별 세션이 닫히면 이전의 맥락을 잊습니다. Kairos는 pgvector 기반 커리어 지식베이스를 통해 사용자의 5년 경력 데이터를 평생 동안 누적 기억하여 개인화된 답변을 제공합니다.

둘째, **에이전트 조작성**입니다. ChatGPT는 텍스트 조언만 주지만, Kairos는 로컬/웹 에이전트 파이프라인을 구동하여 실제 채용 공고 수집, HWP 등 문서 포맷 변환 및 이메일 발송 작업을 직접 수행합니다.

셋째, **환경의 유연성(멀티플랫폼)**입니다. 단순 웹뿐 아니라 스마트폰 앱(React Native Expo), 가볍고 기민한 데스크탑 앱(Tauri v2), 개발자를 위한 VS Code 확장 프로그램 및 터미널 CLI까지 동일한 코어 비즈니스 로직으로 지원합니다."

```
[데모 시나리오 — 5분]

0:00 ~ 0:30 | 로그인 → 대시보드 진입
             "이게 Kairos의 첫 화면입니다"

             "AI가 쓴 자소서를 자연스럽게 바꿉니다"
```

## Q4-3. 데모 중 장애가 나면 어떻게 대처하는가?

**A. 반드시 사전 대비책을 준비해야 한다.**

- LLM API 장애 대비: 모든 기능에 Demo Mode(목업 데이터) 내장되어 있음 [v]
- 네트워크 장애 대비: PWA + 오프라인 큐 + IndexedDB로 기본 작동 [v]
- 실제 API 키 없을 때: DEMO_MODE 자동 전환 (DB 없이도 작동) [v]

**추가 권장**: 화면 녹화본(GIF/영상) 백업 준비 — API가 완전히 먹통일 경우

## Q4-4. "있는 기능을 완벽하게 보여주는 것"이 왜 핵심인가?

**A. 심사 기준이 "기능이 많은가?"가 아닌 "완결성 있게 작동하는가?"이기 때문이다.**

- 시연 전 **3회 이상 리허설** 필수
- 시연 시나리오를 "실패 없이 끝날 수 있는" 순서로 구성
- 불안정한 기능은 시연에 포함하지 말 것

## Q5-2. 예상 질문과 모범 답변을 준비하라.

**A.**

---

**Q: "AI 환각(Hallucination) 문제는 어떻게 해결하나요?"**

A: "두 가지 방법으로 대응합니다.
첫째, pgvector 기반 RAG(검색증강생성)를 사용해 AI가 사용자의 실제 데이터를 참조하게 합니다. 지어낸 정보가 아닌 사실 기반 답변이 나옵니다.
둘째, AI의 답변에 신뢰도 점수(Confidence Score)를 표시하고, 낮은 경우 사용자에게 검증을 요청합니다."

---

**Q: "ChatGPT나 Claude로도 할 수 있는 것 아닌가요?"**

A: "ChatGPT는 대화가 끝나면 저를 잊습니다. Kairos는 제 커리어 전체를 영구적으로 기억합니다. 또한 ChatGPT는 말만 하지만 Kairos의 에이전트는 채용공고를 찾고, 파일을 편집하고, 이메일을 보냅니다. 도구가 아닌 파트너입니다."

---

**Q: "수익 모델이 있나요? 지속 가능한가요?"**

A: "구독 기반 SaaS 모델입니다. 무료/Pro/Team 플랜으로 나뉩니다. AI 비용 최적화를 위해 Anthropic 캐시 제어로 입력 비용을 90% 절감합니다. 또한 사용량 기반 과금 시스템으로 적자가 나지 않도록 자동 제어됩니다."

---

**Q: "보안은 어떻게 되나요? 개인 이력서가 유출되지 않나요?"**

A: "세 가지 보안 장치가 있습니다. 첫째, HttpOnly 쿠키 세션(Better Auth)으로 XSS 공격을 막습니다. 둘째, 문서 파싱은 브라우저에서만 처리해 서버에 원본이 전송되지 않습니다. 셋째, 사용자가 언제든 모든 데이터를 삭제할 수 있습니다."

---

**Q: "실제로 사용해 본 사람이 있나요?"**

A: "현재 프로토타입 단계로 내부 테스트 중입니다. 대회 이후 베타 사용자를 모집해 실제 피드백을 반영하고 6개월 내 서비스 출시를 목표로 합니다."

---

**Q: "면접관이 쓰는 서비스는 없나요?"**

A: "현재는 지원자 중심이지만 향후 B2B 기능으로 기업 HR 담당자가 지원자 풀을 검색하고 면접 질문 뱅크를 관리하는 기능을 추가할 예정입니다."
