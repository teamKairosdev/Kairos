## 사용자 이용 흐름 (User Flow)

### 흐름도 — Mermaid 다이어그램

```mermaid
flowchart TD
    A([🚪 Kairos 접속]) --> B[회원가입 / 로그인]
    B --> C[📋 필수 프로필 입력\n직종 · 기술스택 · 희망직무]
    C --> D{어떤 도움이 필요한가?}

    D -->|이력서 준비| E[📄 이력서 업로드\nPDF / DOCX / HWP]
    D -->|면접 준비| I[🎙️ 모의 면접 시작]
    D -->|채용공고 분석| L[🎯 ATS 분석]

    E --> F[AI 자동 파싱\n텍스트 추출]
    F --> G[3단계 AI 고도화\nDraft → Evaluate → Improve]
    G --> H[✅ 이력서 완성\n점수 표시 · 버전 저장]

    I --> J[직무 · 난이도 설정]
    J --> K[SSE 실시간 AI 면접관\n🤖 thinking 과정 표시]
    K --> K2[면접 평가 · 피드백 확인]

    L --> M[채용공고 JD 붙여넣기]
    M --> N[매칭 스코어 분석\n키워드 갭 · 추천 조언]

    H --> O{더 하고 싶은 게 있나?}
    K2 --> O
    N --> O

    O -->|AI 문체 개선| P[✨ 휴머나이저\nbefore / after 비교]
    O -->|내 경력 검색| Q[🔍 커리어 지식베이스\npgvector 시맨틱 검색]
    O -->|공유하고 싶다| R[🌐 결과 공개 URL 생성\n링크 복사 · SNS 공유]

    P --> S([🎉 취업 준비 완료])
    Q --> S
    R --> S
```

### 흐름 설명 (발표자용 단순 버전)

```
[가입] → [프로필 입력]
    ↓
[이력서 업로드 · AI 고도화]
    ↓
[ATS 채용공고 분석]  ←→  [AI 모의 면접]
    ↓
[키워드 보완 · 피드백 반영]
    ↓
[AI 휴머나이저로 문체 개선]
    ↓
[최종 이력서 완성 · SNS 합격 공유]
```

---

### 핵심 흐름 포인트 (발표 시 강조)

1. **한 번 프로필 입력하면 AI가 내 맥락을 기억** — 다음부터는 설명 불필요
2. **이력서·면접·ATS가 연결됨** — 면접 피드백이 이력서 개선에 반영
3. **결과물에 고유 URL 생성** — ChatGPT처럼 결과를 공유할 수 있음
4. **커리어 지식베이스가 쌓임** — 쓸수록 AI가 나를 더 잘 안다
