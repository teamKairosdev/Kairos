## 1. 왜 CUI만으로는 안 되는가

### 빈 캔버스 공포증 (Blank Canvas Anxiety)

```
[현재 대부분 AI 서비스의 UX]

┌─────────────────────────────────────┐
│                                     │
│                                     │
│         무엇이든 물어보세요           │
│                                     │
│                                     │
│  ┌─────────────────────────────┐   │
│  │ 메시지를 입력하세요...       │   │
│  └─────────────────────────────┘   │
└─────────────────────────────────────┘
```

**이 화면이 사용자에게 주는 심리적 압박:**

| 심리 상태 | 내용 |
|---------|------|
| **인지 과부하** | "이게 뭘 할 수 있는 도구야?" 사용자가 먼저 학습해야 한다 |
| **공백 불안** | 빈 입력창 앞에서 "뭘 써야 하지?"로 시작부터 멈춘다 |
| **기억 의존** | 내가 기능 목록을 기억해야 한다 (recall) — 인지 부담 최대 |
| **실패 공포** | "잘못 입력하면 이상한 답이 나온다" — 시도 자체를 피한다 |
| **진행 불투명** | 내가 지금 어디 있는지, 다음에 뭘 해야 하는지 모른다 |
| **성취감 없음** | 채팅창은 채워지지만 "내가 뭔가를 완성했다"는 느낌이 없다 |

### CUI가 좋은 상황 vs 나쁜 상황

| 상황 | CUI 적합도 | 이유 |
|------|:--------:|------|
| 자유로운 탐색 ("이력서 어떻게 하면 좋을까?") | [v] 좋음 | 구조화되지 않은 생각 표현 |
| 반복적 작업 (이력서 고도화 매번 실행) | [x] 나쁨 | 클릭 1번이면 될 걸 문장으로 써야 함 |
| 구조화된 결과물 (ATS 분석 스코어) | [x] 나쁨 | 텍스트로는 한눈에 비교 불가 |
| 긴장된 상황 (모의 면접) | [x] 나쁨 | 채팅창 형식이 면접 느낌을 죽인다 |
| 빠른 확인 (이력서 점수) | [x] 나쁨 | 채팅창 스크롤이 정보 접근을 방해 |

**결론**: Kairos의 각 기능은 그 기능에 최적화된 고유한 UI 패러다임을 가져야 한다.

## 2. Kairos UX 철학

### 원칙 1 — Recognition over Recall (기억보다 인식)

> 사용자가 기억하게 만들지 않는다. 눈앞에 보여준다.

- [x] 나쁜 예: "이력서 분석을 원하면 '/analyze resume'을 입력하세요"
- [v] 좋은 예: 이력서 카드 위에 마우스를 올리면 "AI 분석 시작" 버튼이 나타난다

### 원칙 2 — Progressive Disclosure (점진적 공개)

> 한 번에 모든 것을 보여주지 않는다. 지금 필요한 것만 보여준다.

```
[나쁜 예]
전체 대시보드에 이력서, 면접, ATS, 휴머나이저, 검색, 
메시지, 커뮤니티, 설정... 전부 한 화면에

[좋은 예]
처음엔 하나만: "이력서를 올려주세요"
이력서가 있으면: "면접 준비할까요?"
면접이 끝나면: "이 공고에 지원해볼까요?"
```

### 원칙 3 — Immediate Feedback (즉각 반응)

> 모든 액션에 0.1초 안에 반응이 있어야 한다. 침묵은 불안이다.

- 버튼 클릭 → 즉시 로딩 스피너
- 파일 드래그 → 드롭존 테두리가 빛남
- AI 처리 중 → 처리 단계가 텍스트로 흐름
- 완료 → 숫자/점수가 애니메이션으로 올라감

### 원칙 4 — Spatial Consistency (공간적 일관성)

> 같은 종류의 정보는 항상 같은 위치에 있어야 한다.

- 페이지 제목은 항상 좌상단
- 실행 버튼은 항상 우하단
- AI 처리 상태는 항상 화면 상단 바
- 점수/결과는 항상 카드 우상단

### 원칙 5 — Flow State Design (몰입 흐름 설계)

> 사용자가 "다음 뭐 해야 하지?"를 고민하지 않아야 한다.  
> 자연스럽게 다음 단계로 이어지는 물길을 만든다.

```
[Kairos 핵심 플로우]

이력서 업로드 완료
    → "이력서 고도화 해볼까요?" 카드 자동 출현
        → 고도화 완료
            → "이 이력서로 ATS 분석 해볼까요?" 자동 제안
                → ATS 완료
                    → "면접도 준비해볼까요?" 제안
```

### 원칙 6 — Data Visualization over Text (텍스트보다 시각화)

> AI의 판단을 텍스트로 설명하지 말고, 시각적으로 보여준다.

- 이력서 점수: 숫자 + 원형 게이지 (텍스트 설명만 하면 안 됨)
- ATS 매칭: 키워드 칩 (초록/빨강), 퍼센트 링
- 면접 평가: 레이더 차트 (논리성/전달력/자신감/전문성)
- AI thinking: 말풍선 + 단계 표시 (처리 과정 보여주기)

## 3. 전체 정보 구조 (Information Architecture)

```
Kairos
│
├──  홈 대시보드
│   ├── 오늘의 커리어 현황 카드
│   ├── "지금 이어서" 바로가기 (마지막 작업)

│   └── 최근 활동 타임라인
│
├──  커리어 개발 [핵심 — 최우선]

│   │   ├── 이력서 목록 (카드 그리드)
│   │   ├── 이력서 에디터 (비주얼 에디터)
│   │   ├── AI 고도화 뷰 (before/after)
│   │   └── 버전 타임라인
│   ├── 면접 스튜디오
│   │   ├── 면접방 (인터뷰 룸 UI)
│   │   ├── 면접 히스토리
│   │   └── 성과 레이더 차트
│   ├── ATS 분석기
│   │   ├── JD 입력 존
│   │   ├── 실시간 매칭 뷰
│   │   └── 키워드 갭 분석
│   ├── 커리어 지식베이스
│   │   ├── 타임라인 뷰
│   │   ├── 지식 그래프 뷰
│   │   └── 태그 클라우드
│   └── AI 도구
│       ├── 휴머나이저
│       └── Q&A 플래시카드
│
├──  AI 어시스턴트 [보조 — 항상 접근 가능]
│   └── 플로팅 버튼 → 사이드 패널로 열림
│
├──  알림 센터
└── ️ 설정
```

### 4.1 이력서 스튜디오 — "공방(Atelier)" 패러다임

> "장인이 작품을 완성해가는 느낌"

#### 진입 화면

```
[이력서 목록 — 카드 그리드]

┌──────────────────────┐  ┌──────────────────────┐
│   삼성 지원용 v3    │  │   카카오 지원용 v1  │
│                      │  │                      │
│  ████████████░░  78점 │  │  █████████░░░░░  65점 │
│                      │  │                      │
│  2025.07.28 수정     │  │  2025.07.25 수정     │
│  [보기] [고도화] [▼] │  │  [보기] [고도화] [▼] │
└──────────────────────┘  └──────────────────────┘

┌──────────────────────┐
│                      │
│      +  새 이력서     │
│    업로드하거나       │
│    처음부터 작성      │
│                      │
└──────────────────────┘
```

**핵심 UX 포인트:**
- 점수가 숫자만이 아닌 프로그레스 바로 시각화
- 카드 hover 시 "AI 고도화" 버튼이 살며시 나타남 (항상 보이지 않음)
- "새 이력서" 카드는 점선 테두리 + 살짝 어두운 톤 (구분)

#### 파일 업로드 존

```
[드래그 앤 드롭 존]

┌──────────────────────────────────────────┐
│                                          │
│                                        │
│                                          │
│   PDF, DOCX, HWP를 여기에 끌어다 놓거나  │
│                                          │
│         [파일 선택]                      │
│                                          │
│   최대 10MB · PDF · DOCX · HWP 지원     │
│                                          │
└──────────────────────────────────────────┘
```

드래그 진입 시:
```
┌──────────────────────────────────────────┐
│                  │
│                                          │
│       여기에 놓으세요                  │
│                                          │
│                  │
└──────────────────────────────────────────┘
```
(테두리가 보라색으로 빛나고, 별빛 파티클 효과)

#### AI 3단계 고도화 뷰 — 핵심

```
[고도화 진행 중 화면]

  ① 분석 중    ──→  ② 평가 중  ──→  ③ 개선 중
  [v] 완료             진행중        ○ 대기

  [좌측 — 원본]                 [우측 — 고도화 중]
  ┌─────────────────────┐       ┌─────────────────────┐
  │                     │       │                     │
  │ 2020년 A회사에서    │       │  ████████████████   │
  │ 개발 업무를 담당했  │  →    │  ████████████       │
  │ 습니다. 주로 웹     │       │  ████████████████   │
  │ 개발을 하였고...    │       │  (생성 중...)       │
  │                     │       │                     │
  └─────────────────────┘       └─────────────────────┘

  이전 점수                         예상 점수
  ████████░░ 62점        →          ██████████ 84점
```

완료 후:
```
[고도화 완료 — Before / After 비교 뷰]

  ┌────────── Before (62점) ──────────┐  ┌────────── After (84점) ───────────┐
  │                                   │  │                                   │
  │ 2020년 A회사에서                  │  │ A회사 백엔드 개발팀에서            │
  │ 개발 업무를 담당했습니다.         │  │ REST API 12개를 설계·구현하여     │
  │ 주로 웹 개발을 하였고...          │  │ 응답 지연을 43% 단축했습니다.     │
  │                                   │  │                                   │
  │ [AI 냄새] [수동표현] [수치없음]  │  │ [v] 능동표현 [v] 수치화 [v] 자연스러움│
  └───────────────────────────────────┘  └───────────────────────────────────┘

  변경된 항목: 7곳    개선 이유 보기 ∨
  +22점 상승  

  [이 버전 저장]  [ATS 분석하러 가기 →]
```

**감정 포인트**: +22점 상승 시 점수가 애니메이션으로 올라가며  이모지와 함께 축하 효과

### 4.2 면접 스튜디오 — "인터뷰 룸(Interview Room)" 패러다임

> 채팅창이 아니다. 진짜 면접 방에 들어가는 느낌.

│    시간: [○20분  ●40분  ○60분]           │

- 음성 입력 옵션 (텍스트와 병행)
- 빨간 "LIVE" 인디케이터 (실전감)

## 5. 감정 설계 — 무의식을 건드리는 순간들

> 사용자가 "왜 좋은지 모르지만 계속 쓰고 싶다"는 상태는 감정에서 온다.

### 5.1 성취 모먼트 (Achievement Moments)

| 트리거 | 반응 | 감정 |
|--------|------|------|
| 이력서 점수 상승 | 점수 애니메이션 + 별 파티클 효과 | 성취감 |
| 면접 완료 | "면접 완료! +13점 향상 " 카드 | 자긍심 |
| ATS 90% 달성 | "거의 다 왔어요!" 축하 배너 | 동기부여 |
| 첫 커리어 항목 등록 | "첫 경험을 기록했어요! 시작이 반입니다" | 유대감 |
| 연속 3일 접속 | "3일 연속이네요 " 상단 알림 | 습관 형성 |

### 5.2 기다림을 즐겁게 만들기 (Waiting as Experience)

AI 처리 중 빈 로딩 스피너 [x]

대신:
```
[이력서 AI 분석 중...]

  01. 텍스트 구조 파악 [v] (0.3초)
  02. ATS 키워드 스캔 [v] (1.2초)
  03. 직무 관련도 평가  (진행 중...)
  04. 개선 포인트 도출 ○
  05. 고도화 문장 생성 ○

  "열심히 분석하고 있어요. 약 15초 남았습니다."
```

→ 각 단계가 완료될 때마다 체크 + 애니메이션

### 5.3 개인화된 인사 (Personalized Touch)

```
[로그인 직후 대시보드]

  안녕하세요, 지훈님 
  오늘도 커리어 목표를 향해 한 걸음 더!

  지난번에 '카카오 지원용 이력서' 고도화를 시작하셨더라고요.
  이어서 하시겠어요?

  [이어서 고도화하기 →]     [나중에]
```

→ 사용자의 마지막 작업을 기억해서 재진입점을 만들어줌

### 5.4 우주 메타포를 UX에 녹이기

| 메타포 | UX 구현 |
|--------|---------|
| "별자리" | 커리어 경험이 노드로 연결되는 지식 그래프 |
| "우주 항해" | 목표 회사까지의 여정을 로드맵 바로 표시 |
| "별의 탄생" | 새 경험 등록 시 노드가 반짝이며 나타나는 애니메이션 |
| "블랙홀" | AI가 데이터를 흡수·분석하는 처리 시각화 |
| "성운" | 커리어 지식베이스 그래프의 배경 효과 |

## 6. Empty State 설계 — 빈 화면을 없애라

> 빈 화면은 사용자를 막막하게 만든다. 모든 빈 상태에 행동 유도가 있어야 한다.

### 이력서 없을 때

```
[x] 나쁜 예:
"이력서가 없습니다."

[v] 좋은 예:
┌─────────────────────────────────────┐
│                                     │
│                                   │
│                                     │
│   아직 이력서가 없어요              │
│                                     │
│   이력서를 올리면 AI가              │
│   3분 안에 개선 포인트를 찾아줍니다 │
│                                     │
│   [PDF 올리기]  [처음부터 작성]     │
│                                     │
│    이런 이력서가 자주 올라와요:  │
│   개발자 이력서 예시  디자이너 예시 │
└─────────────────────────────────────┘
```

### 면접 기록 없을 때

```
[v] 좋은 예:
"첫 AI 면접을 해보세요. 실제 면접보다 100배 안전합니다.
 틀려도 괜찮고, 멈춰도 괜찮습니다."

[지금 바로 면접 시작하기 →]
(예상 소요 시간: 20분)
```

### 커리어 지식베이스 비었을 때

```
[v] 좋은 예:
"당신의 경험이 아직 여기 없어요.

 5년의 경험이 있어도 막상 적으려 하면 생각이 안 나죠.
 그냥 한 줄만 적어보세요. AI가 나머지를 채워줄게요."

[+ 첫 번째 경험 추가하기]
```

## 7. 인터랙션 패턴 라이브러리

### 7.1 AI 처리 상태 표시 패턴

```
[패턴 A — 단계 표시]         [패턴 B — 말풍선 thinking]
분석 중... (1/3)             "이력서를 읽고 있어요..."
평가 중... (2/3)             "약점 패턴을 찾았습니다."
개선 중... (3/3)             "더 나은 표현을 만들고 있어요."
```

**사용 기준**: 패턴 A는 처리 시간 3초 이상, 패턴 B는 대화형 기능(면접, CUI 보조)

### 7.2 스코어 변화 애니메이션

```
[나쁜 예]
65점 → 88점 (즉시 바뀜)

[좋은 예]
65 → 66 → 68 → 71 → 75 → 80 → 84 → 87 → 88
(숫자가 카운트업되며 올라감, 프로그레스 바도 같이 채워짐)
```

### 7.3 카드 진입 애니메이션

- 페이지 최초 로드: 카드들이 위에서 순차적으로 아래로 스르륵 내려옴 (0.1초 간격)
- 새 항목 추가: 왼쪽에서 밀려 들어오는 슬라이드
- 삭제: 오른쪽으로 밀려 사라지는 슬라이드 (되돌리기 토스트 동반)

### 7.4 호버 인터랙션

```
카드 위에 마우스 올리면:
- 카드 살짝 위로 올라옴 (transform: translateY(-4px))
- 그림자 깊어짐 (보라색 glow)
- 숨겨진 액션 버튼 나타남 (opacity 0 → 1)
```

### 7.5 드래그 앤 드롭

```
드래그 시작: 카드가 살짝 회전 + 반투명해짐
드래그 중: 카드 위치에 점선 빈 공간 표시 (자리 예약)
드롭: 제자리에 착지하는 애니메이션
```

## 8. 온보딩 UX — 첫 5분이 전부다

> 사용자는 처음 5분 안에 "이거 쓸 만하다/아니다"를 결정한다.

### 온보딩 4단계 (강제 최소화, 선택 최대화)

```
[Step 1/4] 환영 (30초)
"안녕하세요! 카이로스에 오신 걸 환영해요.
 딱 하나만 물어볼게요."

[Step 2/4] 목표 선택 (30초)
"지금 가장 필요한 게 뭔가요?"

  ○ 이력서를 개선하고 싶어요
  ○ 면접 연습을 하고 싶어요
  ○ 내 이력서가 이 공고에 맞는지 보고 싶어요
  ○ 일단 둘러볼게요

[Step 3/4] 첫 번째 가치 경험 (3분)
→ 선택한 항목으로 바로 이동
→ 이력서 선택 시: 드래그앤드롭 존 바로 표시
→ 면접 선택 시: 직무 입력 후 바로 면접방 입장

[Step 4/4] 성공 경험 (1분)
→ 첫 결과물 확인
→ "첫 이력서 분석 완료! 개선 포인트 4개 발견" 축하
→ 다음 할 일 제안
```

**온보딩 원칙:**
- 회원가입 직후 설문 5개 이상 금지 → 1-2개만
- 빈 화면으로 절대 내보내지 않기
- 첫 가치 경험을 3분 안에

## 9. CUI의 올바른 위치 — 보조 레이어로

> CUI는 전면에 없다. 항상 접근 가능하지만 강요하지 않는다.

### CUI 배치 방식

```
[메인 UI — 전면]              [CUI — 오른쪽 하단 플로팅]

┌──────────────────────┐         ╔══════════╗
│                      │         ║          ║
│  이력서 스튜디오     │         ║   AI   ║  ← 항상 여기에 있음
│  (전체 화면 UX)      │         ║  도우미  ║     클릭하면 열림
│                      │         ╚══════════╝
│  [카드] [카드] [+]   │
│                      │
└──────────────────────┘
```

CUI 클릭 시 오른쪽 사이드 패널로 열림:

```
┌────────────── AI 도우미 ──────────────┐
│                                      │
│  무엇이든 물어보세요                  │
│  또는 아래에서 빠르게 선택하세요:    │
│                                      │
│  [ 이 이력서 개선점 알려줘]        │
│  [️ 면접 질문 미리 봐줘]           │
│  [ 이 공고 분석해줘]              │
│  [ 이 문장 자연스럽게 바꿔줘]     │
│                                      │
│  ┌──────────────────────────────┐   │
│  │ 또는 직접 입력...            │   │
│  └──────────────────────────────┘   │
└──────────────────────────────────────┘
```

**CUI 내에서도 빈 캔버스 공포증 해결:**
- 빠른 선택 버튼 4개 항상 표시
- 컨텍스트 인식: 이력서 페이지에서 열면 "이 이력서 개선점 알려줘" 자동 강조
