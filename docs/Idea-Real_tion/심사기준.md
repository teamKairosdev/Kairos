## 발표 평가 시 고려할 추가 포인트

### 1. 문제 정의의 설득력
- "취업 준비생이 겪는 진짜 문제는 자소서 첨삭이 아니라 **커리어 전반에 대한 통찰 부족**"
- 수많은 AI 자소서 서비스가 있지만, **데이터가 쌓이고 분석되는 커리어 OS는 없다**

### 2. 시연의 임팩트
- 라이브 데모: 이력서 업로드 → AI 분석 → 면접 연습 → ATS 매칭 → 결과 피드백
- SSE 스트리밍 면접: 실시간성 강조 (기술적으로 화려하면서도 UX적으로 직관적)
- 오프라인 PWA 동작: 네트워크 없이도 기본 기능 사용 가능

### 3. 기술의 적절성 (과시 금지)
- "Vercel AI SDK v7 썼습니다" → ❌
- "사용자가 이력서를 올리면 AI가 3단계로 분석하고, 실시간 면접을 보고, ATS 점수를 바로 보여줍니다" → ✅

### 4. 시장성
- 타겟: 경기도 내 고등학생 + 대학생 → 점차 전국 경력직으로 확장
- 수익 모델: 프리미엄 구독 (심층 분석), 기업용 면접관 패널 (B2B)
- 경쟁 우위: 쌓을수록 강력해지는 데이터 Moat
