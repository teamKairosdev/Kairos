Kairos 핵심 정체성 (모든 문서 최상단에 각인할 것)
================================================================================

Kairos는 "커리어의 총체적 추적, 종합적 활용 및 관리를 지원하는
종합 경력개발 에이전트 서비스 플랫폼"이다.

  • Notion/Obsidian처럼 → 사용자의 커리어 전반을 지식베이스로 관리
  • Threads/X처럼       → 성장자극 SNS, 사회연결망 미니서비스
  • AI Agent             → 다중 에이전트 오케스트레이션 + 데이터 분석

AI 자소서 첨삭은 이 빙산의 일각일 뿐이다.
전체는 "커리어 오퍼레이팅 시스템 + 커리어 SNS" 이다.
