## 1. 면접 분야 선택 시스템

지원자 유형에 따라 면접 서비스를 세분화한다.

### 1.1 지원자 유형 구분

| 유형 | 설명 |
|------|------|
| **고졸전형** | 고등학교 졸업 예정자 / 기졸업자 대상, 실무 중심 / 인성 위주 질문 |
| **대졸전형** | 대학(원) 졸업 예정자 / 기졸업자 대상, 전공 지식 + 인성 질문 |
| **경력자 전용** | 경력 이직자 대상, 기술 심층 + 리더십 + 프로젝트 경험 질문 |

### 1.2 유형별 맞춤 서비스

- **고졸전형**: 기본 인성 질문, 직무 적합도 검사, 학습 태도 평가
- **대졸전형**: 전공 기반 기술 질문, STAR 기법 답변 유도, 전공 프로젝트 평가
- **경력자 전용**: 포트폴리오 기반 심층 질문, 리더십/커뮤니케이션 평가, 협업 경험 분석

## 2. 필수 프로필 생성 시스템

회원 가입 후 서비스 이용 전 **프로필 생성을 강제**한다.

### 2.1 프로필 필드

| 항목 | 설명 |
|------|------|
| **직종** | 예: 개발자, 디자이너, PM, 마케터 등 |
| **관련 분야** | 예: 웹 프론트엔드, 데이터 엔지니어링, UI/UX |
| **관심 분야** | 예: AI, DevOps, 보안, 클라우드 |
| **경력 요약** | 직무 경험 및 주요 성과 (선택) |
| **희망 직무** | 지원하려는 직무 리스트 |

### 2.2 프로필 활용

- AI 면접 질문 맞춤화에 사용
- ATS 분석 시 기준 데이터로 활용
- 검색 엔진에 인덱싱되어 면접관/기업이 검색 가능

## 3. 통합 검색 시스템 (공통 + 분야별)

면접관과 일반 사용자가 모두 사용할 수 있는 고급 검색 기능.

### 3.1 공통 검색

- 키워드 기반 통합 검색 (프로필, 이력서, 포트폴리오, 게시글 등)
- AI가 검색 의도를 분석하여 최적 결과 반환

### 3.2 분야별 검색 (면접관 전용)

- **분야별 검색**: 직종 / 기술 스택 / 경력 연차 / 학력 등 필터링
- **면접 성과도 검색**: 모의 면접 점수, 개선율, 강점/약점 분석 결과 기반 검색
- **경력 검색**: 이전 회사, 직무, 프로젝트 경험, 보유 기술 기반 검색

### 3.3 AI 추천 매칭

- 검색 결과 상단에 **AI가 직접 검색 조건에 가장 적합한 인재를 추천**
- 유사도 점수와 함께 매칭 사유 표시
- pgvector 시맨틱 검색 엔진 활용 (기존 인프라 재사용)

## 4. 메시지 기능

면접관이 마음에 드는 인재를 발견했을 때 연락할 수 있는 내부 메시지 시스템.

### 4.1 기본 기능

- 모든 사용자(지원자, 면접관, 기업) 간 1:1 메시지 송수신
- 메시지함 UI (받은 메시지, 보낸 메시지, 읽음/안읽음 표시)
- 인재 프로필에서 "메시지 보내기" 버튼으로 바로 연락

### 4.2 대화 저장 정책

| 조건 | 처리 |
|------|------|
| 대화가 있었던 날 | 해당 날짜의 메시지 자동 저장 |
| 대화가 전혀 없던 날 | 저장하지 않음 (빈 일자는 스킵) |

- 저장 주기: 매일 자정(00:00) batch 작업으로 전날 대화 내역 저장
- 저장 대상: 메시지 본문, 발신자, 수신자, 타임스탬프

## 5. 커뮤니티 시스템

취업 준비자와 면접관 각각을 위한 분리된 커뮤니티 공간.

### 5.1 취업준비자 커뮤니티

- 면접 후기 공유
- 자소서/이력서 피드백 요청
- 스터디 그룹 모집
- 질문 & 답변 게시판
- 익명 게시판 (부담 없이 질문 가능)

### 5.2 면접관 커뮤니티

- 면접 질문 노하우 공유
- 인재 평가 기준 토론
- 채용 트렌드 및 산업 정보 공유
- 기업 간 네트워킹

---

## 6. 기업 게시판 시스템

기업이 자유롭게 홍보 및 채용 공고를 게시할 수 있는 기능.

### 6.1 게시판 생성

- 기업 계정이 게시판을 만들 수 있음
- 게시물 타입: 채용 공고, 기업 홍보, 설명회/행사 안내
- 작성된 게시글은 자동으로 검색 인덱싱

### 6.2 메인 화면 게시판 (캐러셀)

- 메인화면 중앙 상단에 **가로 스크롤 캐러셀 게시판** 배치
- 마우스 휠 또는 터치 드래그로 좌우 회전
- 최신순 / 추천순 정렬
- 각 카드에는 썸네일, 제목, 기업명, 간단 설명 표시
