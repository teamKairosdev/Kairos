# 개인을 넘어 국가와 사회로

> **副제목**: Kairos가 해결하는 사회 구조적 문제  
> **관점**: 개인 서비스 → 사회 인프라  
> **작성일**: 2026-07-29

---

## 서론 — 왜 Kairos는 사회 문제를 다뤄야 하는가

Kairos를 단순히 "취업 준비 도구"로 보면 시장이 수백만 명의 취업 준비생으로 끝난다.  
그러나 채용 시장은 **정보 비대칭, 인력 미스매치, 기회 불평등**이라는 구조적 문제를 안고 있다.

> **취업 준비생 1명의 문제 ≠ 개인의 게으름**  
> **= 정보 접근성 격차 + 피드백 부재 + 채용 시장 불투명 + 지역 격차**

Kairos가 이 문제를 해결하면, 그 데이터는 **사회 전체를 위한 인프라**가 된다.

---

## 1. 청년 고용 문제 — 한국의 구조적 현실

### 현황

| 지표 | 수치 | 출처 |
|------|------|------|
| 청년 실업률 (15-29세) | 약 7-8% | 통계청 2025 |
| 취업 준비 평균 기간 | 약 11개월 | 고용노동부 |
| 서류 전형 탈락 후 피드백 받은 비율 | 1% 미만 | 취준생 설문 |
| 채용공고와 실제 직무 간 미스매치 경험 | 약 67% | 한국고용정보원 |
| 경기도 청년 인구 (15-34세) | 약 270만 명 | 경기도 통계 |

### 핵심 문제

```
[채용 시장의 3대 정보 비대칭]

① 지원자 → 기업 (지원자가 모르는 것)
   - 이 회사가 실제로 어떤 사람을 원하는가
   - ATS 시스템이 어떤 기준으로 서류를 거르는가
   - 면접에서 무엇을 주로 보는가

② 기업 → 지원자 (기업이 모르는 것)
   - 이 지원자의 실제 역량이 얼마나 되는가
   - 이력서에 없는 잠재력은 무엇인가
   - 이 사람이 우리 팀에 맞는가

③ 사회/정부 → 시장 (정책 입안자가 모르는 것)
   - 어떤 스킬이 실제로 부족한가
   - 어떤 지역에서 어떤 직무가 가장 많이 필요한가
   - 취업 준비 과정에서 어떤 장벽이 가장 크게 작용하는가
```

**Kairos가 쌓는 데이터는 이 3가지 비대칭을 모두 해소할 수 있다.**

## 2. 이해관계자별 가치 맵

### 2.1 취업 준비생 (Job Seeker) — 1차 사용자

**Pain Point:**
- 이력서 11개 버전이 PC에 흩어짐
- 탈락 이유를 알 수 없음
- AI 도움이 일회성 (맥락 없음)
- 지방 거주자 vs 수도권 거주자 정보 격차

**Kairos 제공 가치:**
- AI 이력서 고도화 (ATS 최적화)
- 실시간 AI 모의 면접 + 피드백
- 커리어 지식베이스 (내 경험을 AI가 기억)
- 지역 무관하게 동일한 취업 준비 인프라 접근

**사회적 의미:**
> 수도권 대학 진학·취업 준비 인프라 없는 지방 청년에게  
> 동일 수준의 커리어 코칭을 제공하는 **교육 형평성 인프라**

---

### 2.2 대학교 (University) — B2B 파트너

**Pain Point:**
- 취업률 통계는 있지만, 왜 탈락하는지 데이터가 없음
- 학생별 취약 역량을 파악할 도구 없음
- 취업지원센터의 1:1 코칭이 인력 부족으로 한계

**Kairos 제공 가치:**

```
[대학 관리자 대시보드 — 비전]

학과별 이력서 완성도 평균: 컴공 72점 / 전자공학 68점 / 경영 71점
가장 많이 부족한 키워드 TOP5: [포트폴리오] [수치화] [협업경험] ...
면접 통과율 낮은 학년: 3학년 (평균 45%)
최다 지원 직무: 백엔드 개발 (34%) / 프론트엔드 (22%) / PM (18%)
```

- 학교 단위 취업 준비 현황 집계 (익명 집계)
- 부족한 역량 그룹 자동 식별 → 맞춤 커리어 프로그램 설계
- 취업지원센터 1:1 코칭의 AI 보조 도구

**수익 모델**: 대학 기관 구독 (B2B) — 학생당 월 X원 라이선스

---

### 2.3 기업 HR (Employer) — B2B 고객

**Pain Point:**
- 연간 수백 장 이력서를 1명이 검토
- 잘 쓴 이력서 ≠ 잘 하는 사람 (이력서 어뷰징 판별 불가)
- 면접 질문 매번 새로 준비 (비효율)
- 좋은 지원자를 놓쳐도 모름

**Kairos 제공 가치:**

```
[HR 담당자용 기능 — 비전]

① 지원자 역량 투명화
   - Kairos 검증 배지: "이 이력서는 AI 어뷰징 없이 작성됨"
   - 면접 모의 결과 자발적 공개 옵션 (지원자 동의 시)

② 직무별 맞춤 면접 질문 뱅크
   - 직무 + 경력 연차 입력 → 맞춤 면접 질문 자동 생성
   - 이전 면접에서 효과적이었던 질문 순위 학습

③ 인재 발굴
   - 공개 프로필 검색 (지원자 동의 시)
   - pgvector 시맨틱 검색: "3년 이상 FastAPI 경험 + AWS 실무" 검색

④ 채용 성과 분석
   - 이 직무 합격자 평균 이력서 점수는?
   - 어떤 키워드가 최종 합격자에게 공통적으로 있었나?
```

---

### 2.4 정부 및 사회단체 — 정책 데이터 공급

**Pain Point:**
- 청년 고용 정책은 있지만 실효성 측정이 어려움
- 지역별 인력 수요-공급 불균형 파악 도구 없음
- 취업 준비생 실태 조사가 설문 중심 (정밀도 낮음)

**Kairos 제공 가치 — 집계 인사이트 API:**

```
[정부/사회단체용 집계 데이터 — 익명화·집계된 형태로만 제공]

① 지역별 취업 준비 현황
   - 경기도 수원시 20대 이력서 평균 완성도: 68점
   - 인천 vs 서울 취업 준비 격차: 평균 14점 차이

② 직무별 스킬 갭 (Skill Gap Analysis)
   - 현재 가장 부족한 스킬 전국 TOP10
   - 기업이 원하는 스킬 vs 지원자가 보유한 스킬 불일치 지표

③ 채용 시장 실시간 트렌드
   - 이번 달 가장 많이 검색된 채용공고 키워드
   - 직무별 경쟁률 변화 추이

④ 취업 준비 장벽 실태
   - 가장 많이 틀리는 면접 질문 유형
   - 이력서에서 가장 많이 빠지는 항목
   - 지역/학력별 격차 지표

→ 정부 청년 고용 정책 근거 데이터로 활용
→ 경기도청, 고용노동부, 한국고용정보원 등 협업 기회
```

**수익 모델**: 정부 데이터 라이선스 (B2G) — 집계 익명 데이터 제공 계약

---

### 2.5 교육기관 및 부트캠프

- 수강생의 취업 준비 성과를 정량적으로 추적
- 어떤 커리큘럼이 실제 취업에 도움이 됐는지 데이터화
- 수료생 커리어 포트폴리오 플랫폼으로 활용

## 3. 사회 문제 해결 프레임

```
[Kairos 사회적 가치 구조]

개인 레이어 (직접 사용자)
    취업준비생 ─── 이력서·면접·ATS로 개인 경쟁력 향상
         │
         │ 데이터 생성 (익명·집계)
         ▼
플랫폼 레이어 (Kairos 데이터 허브)
    개인 → 집계 → 인사이트 추출
         │
    ┌────┴─────────────────────────────┐
    │                                  │
    ▼                                  ▼
기업 레이어                      사회/정부 레이어
기업 HR → 인재 탐색 효율화      정책 입안 → 증거기반 청년 고용정책
면접 질문 자동화                지역별 스킬 갭 해소 프로그램
채용 성과 분석                  교육-취업 연결 고리 데이터
```

## 4. 지역사회 기여 — 경기도 특화 전략

> 대회 주최: 경기도경제과학진흥원 — 이 관점을 발표에 반드시 넣어야 한다

### 경기도 청년 고용 특수성

| 경기도 특성 | 수치 |
|-----------|------|
| 청년 인구 (15-34세) | 약 270만 명 (전국 최대) |
| 경기도 거주 + 서울 취업 비율 | 약 45% |
| 지역 내 일자리 vs 청년 인구 비율 불균형 | 심각 |
| 경기 남부 vs 북부 취업 인프라 격차 | 현저 |

### Kairos의 경기도 기여 시나리오

```
시나리오: 경기 북부 포천 거주 고등학생 A (18세)

현재:
- 서울 취업 스터디 그룹 참여 불가 (거리)
- 학교 취업지원센터 없음 (고교)
- 인터넷에서 정보 찾는 것이 전부

Kairos 이후:
- 스마트폰으로 Kairos 접속 (PWA)
- AI가 동일 수준의 이력서 코칭, 면접 준비
- 경기도 청년 취업 지원 프로그램과 연계 알림
- 지역 기업 채용공고 자동 매칭

→ 취업 준비의 지역 격차 해소
```

## 5. 장기 사회적 비전 — 커리어 인프라

> 10년 후 Kairos가 가야 할 곳

**Phase A (현재~2027)**: 개인 서비스로 사용자 기반 확보  
**Phase B (2027~2028)**: 대학·기업 B2B로 확장, 데이터 축적  
**Phase C (2028~2030)**: 국가 청년 고용 인프라로 자리매김

```
[2030 Kairos 비전]

- 전국 200개 대학 취업지원센터 연동
- 30만 기업 채용 데이터 연결
- 500만 취업준비생 커리어 데이터 보유
- 고용노동부 공식 데이터 파트너
- 스킬 갭 리포트 연간 발간 (정책 근거 자료)

→ "한국 인재 시장의 LinkedIn + Glassdoor + 정부 고용 인프라"
```

## 발표 활용 — "사회 문제 해결" 슬라이드용 핵심 문장

> 심사 기준 "기대 효과(15점)" — 사회적 기여도 + 지속가능성 공략

**발표 멘트:**
> "이수민 한 명의 문제가 해결되면 끝이 아닙니다.  
> 이수민 100만 명의 데이터가 쌓이면,  
> 대학은 어떤 교육이 실제 취업에 도움이 됐는지 알 수 있고,  
> 기업은 어떤 역량을 가진 인재가 부족한지 알 수 있고,  
> 정부는 어느 지역 청년에게 어떤 지원이 필요한지 알 수 있습니다.  
> Kairos는 도구가 아니라 인프라입니다."
