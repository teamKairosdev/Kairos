## 1. 종합 시스템 아키텍처 블루프린트

Kairos는 **자율형 에이전트**와 **성장 자극형 SNS 커뮤니티**의 가치를 극대화하기 위해, 정적 콘텐츠 전송(Astro)과 풍부한 애플리케이션 상태 제어(Nuxt 4)를 물리적으로 분리한 **하이브리드 프론트엔드 파이프라인**을 채택하고, NeonDB와 Redis Cloud를 결합한 고효율 데이터 파이프라인을 구축합니다.

```
                  ┌────────────────────────────────────────┐
                  │              클라이언트 브라우저       │
                  └──────┬──────────────────────────┬──────┘
                         │ (정적/SNS/SEO)           │ (대시보드/에이전트/CUI)
                         ▼                          ▼
               ┌───────────────────┐      ┌───────────────────┐
               │    Astro Shell    │      │    Nuxt 4 Shell   │
               │ (Islands Arch.)   │      │   (Hybrid SPA)    │
               └─────────┬─────────┘      └─────────┬─────────┘
                         │                          │
                         ├──────────────────────────┤
                         │ (Edge Router / Vercel)   │
                         ▼                          ▼
               ┌────────────────────────────────────────┐
               │         Nitro API Gateway              │
               │  - Better Auth / Rate Limiting (Redis) │
               │  - Model Router (Anthropic SDK v7)     │
               └─────────┬──────────────────────────┬───┘
                         │                          │
                         │ (Session/Cache/Limit)    │ (Data/Vector query)
                         ▼                          ▼
               ┌───────────────────┐      ┌───────────────────┐
               │    Redis Cloud    │      │   Neon Postgres   │
               │ (Upstash / Cache) │      │   (with pgvector) │
               └───────────────────┘      └───────────────────┘
```

## 2. 프론트엔드 멀티 프레임워크 아키텍처

### 2.1 Astro (아일랜드 아키텍처 - Island Architecture)

*   **적용 영역**: 커리어 공개 SNS (`r/*` 채널), 랜딩 페이지, 기업 정보 인텔리전스 개요, 공식 블로그 및 회사 소개.
*   **핵심 목적**: **초고속 웹 로드 시간 (LCP < 1.2s)** 및 **SEO(검색엔진 최적화) 성능 극대화**.
*   **동작 매커니즘**:
    *   기본적으로 자바스크립트가 배제된 순수 정적 HTML을 서빙하여 초기 렌더링 성능을 극대화합니다.
    *   커뮤니티 글의 "좋아요", "댓글 컴포넌트", "실시간 연봉 비교 필터" 등 상호작용이 필요한 특정 부분만 **Astro Island**로 선언하여 개별 라이드하이드레이션(Partial Hydration)을 수행합니다.
    *   `client:visible` 속성을 사용하여 사용자의 스크롤이 해당 컴포넌트에 닿았을 때만 리액티브 자바스크립트 코드를 동적으로 로드 및 실행합니다.

### 2.2 Nuxt 4 (하이브리드 SPA & SSR)

*   **적용 영역**: 이력서 AI 고도화 스튜디오, SSE 실시간 모의 면접관 UI, ATS 실시간 매칭 레이더, 개인 설정 및 알림 센터.
*   **핵심 목적**: **복잡한 애플리케이션 상태(State) 제어, 실시간 스트리밍(SSE) 연동, 부드러운 화면 전환(Page Transitions)**.
*   **동작 매커니즘**:
    *   대시보드 내부 진입 시 클라이언트 사이드 라우팅이 지배하는 **SPA(Single Page Application) 모드**로 동작하여 네이티브 앱과 같은 사용성을 구현합니다.
    *   실시간 면접 및 AI Thinking 상태를 Reactivity API로 관리하며, SSE 스트리밍 데이터를 가볍게 수신 및 버퍼링 처리합니다.
    *   보안이 중요한 사용자 인증 기반 API(Better Auth) 연동 세션을 Nitro 서버 엔진을 통해 안전하게 중계합니다.

## 3. 기능별 렌더링 전략 매핑 (Rendering Strategy)

성능 향상과 서버 비용 절감을 위해 페이지 특성에 맞게 렌더링 방식을 다르게 설계합니다.

| 페이지 종류 | 적용 방식 | 렌더링 전략 | 설명 |
|:---|:---:|:---:|:---|
| **랜딩 / 소개 페이지** | Astro | **SSG** (정적 사이트 생성) | 빌드 시 완성된 정적 HTML 전송, 로드 속도 1위 |
| **커뮤니티 피드 (SNS)** | Astro | **ISR** (증분 정적 재생성) | 1분 주기(or 온디맨드) 캐시 갱신으로 NeonDB 쿼리 부하 최소화 |
| **기업 정보 (인텔리전스)** | Astro | **ISR** | 매일 00:00 배치 갱신된 데이터를 기반으로 ISR 페이지 캐싱 |
| **이력서 스튜디오** | Nuxt 4 | **SPA** | 실시간 로컬 파싱 및 드래그앤드롭 반응 속도 최우선 |
| **실시간 모의 면접관** | Nuxt 4 | **SPA + SSE** | 에이전트 추록 및 면접 스트리밍 처리 최적화 |
| **어드민 / 대시보드 홈** | Nuxt 4 | **SSR** | 사용자 개인화 데이터 실시간 조합 및 보안 세션 검증 |

### ISR (Incremental Static Regeneration) 구현 설계

Astro 또는 Nuxt Nitro CDN 레이어에서 기업 연봉 트렌드 및 통계처럼 무거운 pgvector 집계가 필요한 페이지를 ISR로 처리하여 **NeonDB의 쿼리 발생 빈도를 99.9% 낮춥니다**.

```typescript
// server/routes/companies/[id]/stats.ts
export default defineEventHandler(async (event) => {
  // ISR 설정: 24시간 동안 정적 캐싱 유지, 백그라운드에서 백업 검증(Stale-While-Revalidate)
  setResponseHeaders(event, {
    'Cache-Control': 'public, max-age=0, s-maxage=86400, stale-while-revalidate=600',
  })

  const companyId = getRouterParam(event, 'id')
  
  // 무거운 pgvector 시맨틱 매칭 및 DART 집계 쿼리 실행
  return await db.execute(sql`
    SELECT * FROM company_intelligence_cache WHERE company_id = ${companyId}
  `)
})
```

## 4. 데이터 계층 및 분산 스토리지 설계

### 4.1 Neon PostgreSQL (NeonDB)

*   **역할**: 관계형 데이터 영구 저장소 및 시맨틱 벡터 저장소.
*   **핵심 기술**: Serverless Postgres Autoscaling, **`pgvector`** (1536차원 OpenAI/Haiku 임베딩 벡터 지원).
*   **최적화 전략**:
    *   **커넥션 관리**: Vercel Serverless 환경의 커넥션 풀 고갈을 방지하기 위해 Neon의 **Connection Pooling (PgBouncer)** 포트(5432 대신 6543) 사용 필수.
    *   **시맨틱 인덱싱**: 대용량 벡터 비교 시 무차별 대입 대신 **HNSW (Hierarchical Navigable Small World)** 인덱스를 사용하여 시맨틱 매칭 연산 속도를 10ms 이하로 단축.

```sql
-- pgvector index 생성 SQL 예시
CREATE INDEX ON job_postings 
USING hnsw (content_vector vector_cosine_ops)
WITH (m = 16, ef_construction = 64);
```

### 4.2 Redis Cloud (Upstash Redis)

*   **역할**: 글로벌 분산 캐시, 실시간 세션 스토어, API 가드레일(Rate Limiter).
*   **핵심 최적화**:
    1.  **세션 캐싱 (Better Auth)**: DB 쿼리 없이 사용자 세션을 빠르게 검증할 수 있도록 세션 메타데이터를 Redis에 캐싱.
    2.  **글로벌 Rate Limiting**: AI API 오용 및 디도스 공격 방지를 위해 IP 및 사용자 토큰 기준 초당/분당 요청 제어.
    3.  **LLM 응답 시맨틱 캐싱 (Semantic Cache)**: 동일하거나 유사한 프롬프트가 들어올 경우 OpenAI/Claude API로 쿼리를 날리지 않고 Redis에 저장된 캐시 값 즉시 반환.

```typescript
// server/lib/semanticCache.ts
import { Index } from "@upstash/vector"

const vectorIndex = new Index({
  url: process.env.UPSTASH_VECTOR_REST_URL,
  token: process.env.UPSTASH_VECTOR_REST_TOKEN,
})

async function getSemanticCache(prompt: string): Promise<string | null> {
  const embedding = await generateEmbedding(prompt)
  const results = await vectorIndex.query({
    vector: embedding,
    topK: 1,
    includeMetadata: true,
  })

  // 코사인 유사도가 0.96 이상인 경우, 완벽히 동일한 질문으로 처리하여 캐시 히트
  if (results.length > 0 && results[0].score > 0.96) {
    return results[0].metadata?.response as string
  }
  return null
}
```

## 5. 아키텍처 기준 디바이스별 데이터 매핑

각 아키텍처 구성 요소가 디바이스별로 최적화되어 데이터를 교환하는 매트릭스입니다.

```
[로컬 디바이스 / 플랫폼]
  ├── Chrome Extension ── (Manifest V3 Web Worker) ──→ API Gateway (Nitro)
  ├── Desktop App ──────── (Tauri Local Port / SQLite) ──→ API Gateway (Nitro)
  ├── Mobile App ───────── (React Native Native Bridge) ─→ API Gateway (Nitro)
  └── Web Browser ──────── (Astro / Nuxt Local Fetch) ──→ API Gateway (Nitro)
                                                               │
                                         ┌─────────────────────┴─────────────────────┐
                                         ▼                                           ▼
                                 [ Neon pgvector DB ]                       [ Redis Cloud Cache ]
                              - 영구 커리어 히스토리 저장                 - 실시간 Rate Limit 검증
                              - 시맨틱 경험 노드 검색                    - Better Auth 세션 토큰 매칭
```
