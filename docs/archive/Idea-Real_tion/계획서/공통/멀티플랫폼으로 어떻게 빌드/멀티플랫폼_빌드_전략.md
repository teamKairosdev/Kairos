## 1. 멀티플랫폼 아키텍처 개요

Kairos는 단순한 웹 앱이 아닌 개인의 커리어 전 생애를 대신 행동하고 관리하는 **"Career OS"**입니다. 사용자는 개발 환경(IDE), 터미널(CLI), 모바일(App), 웹 브라우저 등 다양한 환경에서 실시간으로 커리어를 기록하고 에이전트를 조작할 수 있어야 합니다.

이를 효율적으로 구현하기 위해 **Turborepo 기반의 모노레포(Monorepo)** 구조를 채택하여 공통 비즈니스 로직, API 클라이언트, 데이터 스키마를 단일 라이브러리로 관리하고, 플랫폼별 전용 쉘(Shell)을 씌워 빌드하는 **"Core-Shell" 아키텍처**를 적용합니다.

### packages/ (공통 라이브러리)
1. **`core-api`**: 백엔드 Vercel/Nitro 서버와 통신하는 SDK. Better Auth 연동 세션 관리 및 에러 핸들러 내장.
2. **`core-storage`**: 플랫폼 환경에 맞는 로컬 데이터베이스 어댑터. (Web/PWA/Chrome Ext: IndexedDB, Mobile/Desktop: SQLite).
3. **`core-agent`**: AI 에이전트의 프롬프트 템플릿, Tool 스키마 및 로컬 LLM(@huggingface/transformers) 실행기.
4. **`core-design`**: 플랫폼 간 디자인 일관성을 유지하기 위한 공통 디자인 토큰 (CSS 변수, HSL 컬러 팔레트, 아이콘 리소스).

## 3. 플랫폼별 빌드 전략 & 기술 스택

### 3.1 Web: Nuxt 4 (SPA / PWA)

*   **역할**: 모든 플랫폼의 기준이 되는 포털이자 핵심 관리 대시보드.
*   **빌드 기술**: Nuxt 4, Vite, `@vite-pwa/nuxt`.
*   **특징**:
    *   **SPA/SSR 하이브리드**: 대시보드 및 에이전트 조작부는 고성능 SPA로 작동하며, SEO가 중요한 커리어 오픈 SNS 영역은 SSR로 렌더링.
    *   **PWA**: 서비스 워커를 통해 정적 에셋을 캐싱하고 오프라인 상태에서도 이력서 작성 및 이전 면접 히스토리 조회가 가능하게 설정.
    *   **로컬 파싱**: 브라우저 스레드에서 `pdfjs-dist` 및 `mammoth`를 사용해 서버 리소스 낭비 없이 클라이언트 사이드에서 즉시 파일 추출.

### 3.2 Mobile App: React Native (Expo)

*   **역할**: 이동 중 실시간 모의 면접(음성 인터랙션) 및 실시간 채용 알림 수신.
*   **빌드 기술**: React Native, Expo SDK, Expo EAS (Expo Application Services).
*   **특징**:
    *   **웹뷰 하이브리드**: 이력서 편집 등 복잡한 UI는 Nuxt 웹뷰를 사용하고, 카메라/마이크 가속 및 푸시 알림 등 네이티브 성능이 필요한 곳은 React Native 코어 사용.
    *   **음성 인터랙션**: 디바이스 자체 STT/TTS API를 래핑하여 에이전트 면접 음성 입출력 최적화.
    *   **로컬 보안 저장소**: `expo-secure-store`를 사용해 Better Auth 인증 토큰 안전하게 암호화 보관.

### 3.3 Desktop App: Tauri v2 (Rust + Web UI)

*   **역할**: 로컬 HWP 파일 편집기 연동, 파일 시스템 조작, 로컬 에이전트 백그라운드 데몬 실행.
*   **빌드 기술**: Tauri v2, Rust, Nuxt 4 SPA 빌드 산출물.
*   **특징**:
    *   **초경량화**: Electron 대비 빌드 용량 90% 절감 (10MB 내외), 메모리 점유율 극소화.
    *   **Rust 네이티브 바인딩**: 로컬 OS 파일 시스템 접근, HWP 파일 바이너리 조작 및 로컬 프로세스 백그라운드 실행을 Rust 코어로 구현하고 Webview로 메시지 전달.
    *   **Tauri v2 플러그인**: `tauri-plugin-sql`을 통해 로컬 SQLite 암호화 데이터베이스 운용.

### 3.4 Browser Extension: Chrome Extension (Manifest V3)

*   **역할**: 사람인, 잡코리아, 링크드인 등 외부 채용 사이트 탐색 시 실시간 공고 추출 및 Kairos 데이터 연동.
*   **빌드 기술**: Web Extension API, Manifest V3, Vite.
*   **특징**:
    *   **Content Script**: 사용자가 사람인 공고 페이지에 진입하면 DOM을 분석하여 채용 조건(JD) 텍스트를 자동 파싱.
    *   **Popup UI**: 클릭 시 미니 대시보드가 열려 현재 보고 있는 공고와 내 이력서의 **ATS 실시간 매칭률**을 즉시 표시.
    *   **Background Service Worker**: Kairos 백엔드 에이전트와 통신하여 백그라운드에서 백엔드 DB로 공고 스크랩 자동 전송.

### 3.5 IDE Extension: VS Code / VSX Extension

*   **역할**: 개발자 사용자가 코드 작성 도중 자신의 프로젝트 코드를 기반으로 실시간 커리어 지식베이스에 경험을 전송 및 이력서 업데이트.
*   **빌드 기술**: VS Code Extension API, Yeoman Code Generator, `vsce` 패키저.
*   **특징**:
    *   **로컬 Git 분석**: 현재 프로젝트의 Git commit 로그와 코드를 로컬에서 파싱하여 개발자의 오늘 업무 성과를 자동 요약.
    *   **Command Palette 통합**: `/Kairos: Record Today's Work` 명령을 통해 오늘 구현한 핵심 알고리즘이나 트러블 슈팅을 커리어 지식베이스 노드로 즉시 등록.
    *   **사이드바 웹뷰**: VS Code 내부 사이드바 패널에 Kairos 미니 대시보드를 임베드하여 개발 환경 이탈 없이 커리어 모니터링 가능.

### 3.6 Agent CLI (Command Line Interface)

*   **역할**: 터미널 환경을 선호하는 개발자를 위해 CLI 명령으로 이력서 버전을 깃처럼 제어하고 에이전트 실행.
*   **빌드 기술**: Node.js/TypeScript (esbuild 단일 바이너리 빌드) 또는 Go 언어 빌드.
*   **특징**:
    *   **깃 스타일 커맨드**:
        *   `kairos init`: 현재 디렉토리 커리어 지식베이스 활성화
        *   `kairos resume push <file.pdf>`: 이력서 업로드 및 AI 고도화 루프 실행
        *   `kairos status`: 현재 내 이력서 완성도 및 ATS 매칭 스코어 출력
        *   `kairos interview start`: 터미널 환경에서 대화형 CUI AI 모의면접 진행
    *   **로컬 캐시**: CLI 환경에서 동작 가속을 위해 `.kairos` 로컬 폴더 내에 임시 토큰 및 로컬 캐시 관리.

## 4. 데이터 공유 및 상태 동기화 전략

플랫폼이 다양화될수록 각 디바이스에 분산된 데이터의 일관성을 유지하는 것이 중요합니다.

```
┌────────────────────────────────────────────────────────┐
│                   데이터 동기화 아키텍처                │
│                                                        │
│   [클라이언트 앱] (Web / App / Desktop / Extension)     │
│          │                                             │
│          ├── 1. 로컬 저장 (IndexedDB / SQLite / Cache) │
│          │                                             │
│          ▼ 2. 백그라운드 동기화 (REST API / SSE)        │
│                                                        │
│   [백엔드 게이트웨이] (Vercel / Nitro API)              │
│          │                                             │
│          ▼ 3. 실시간 분산 원장 및 영구 저장             │
│                                                        │
│   [메인 데이터베이스] (Neon pgvector / Cloudflare R2)  │
└────────────────────────────────────────────────────────┘
```

1. **오프라인 우선(Offline-First) 라이프사이클**:
   - 네트워크 연결이 끊긴 상태에서는 각 플랫폼 내부의 `core-storage`에 이벤트를 큐(Queue)로 기록.
   - 온라인 복귀 시 백그라운드 서비스 워커가 Sync API를 호출하여 Neon PostgreSQL 메인 DB와 충돌 없는 순차 병합(Last-Write-Wins)을 수행.
2. **실시간 알림 및 상태 푸시**:
   - 에이전트가 백그라운드에서 채용공고 분석을 끝내면, Server-Sent Events(SSE) 또는 모바일 푸시 알림(FCM/APNS)을 통해 웹 브라우저, 모바일 앱, 데스크탑 트레이 아이콘에 실시간 배지를 활성화.

## 5. CI/CD 및 멀티플랫폼 빌드 파이프라인

모노레포의 장점을 극대화하기 위해 **GitHub Actions**와 **EAS / Tauri Bundler**를 연동하여 하나의 PR 머지 시 모든 플랫폼 산출물을 자동 빌드 및 배포합니다.

```yaml
# .github/workflows/release-multoplatform.yml
name: Release Kairos Multi-Platform

on:
  push:
    tags:
      - 'v*.*.*'

jobs:
  # 1. 공통 라이브러리 검증 및 테스트
  validate-core:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
      - run: pnpm install
      - run: pnpm build --filter="./packages/*"
      - run: pnpm test --filter="./packages/*"

  # 2. 웹 (Nuxt 4 / PWA) 배포
  deploy-web:
    needs: validate-core
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pnpm install
      - name: Deploy to Vercel
        run: npx vercel --token=${{ secrets.VERCEL_TOKEN }} --prod

  # 3. 데스크탑 (Tauri v2) 빌드
  build-desktop:
    needs: validate-core
    strategy:
      matrix:
        platform: [macos-latest, ubuntu-22.04, windows-latest]
    runs-on: ${{ matrix.platform }}
    steps:
      - uses: actions/checkout@v4
      - name: install Rust stable
        uses: dtolnay/rust-toolchain@stable
      - run: pnpm install
      - name: Build Tauri App
        uses: tauri-apps/tauri-action@v2
        env:
          TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_PRIVATE_KEY }}
        with:
          tagName: ${{ github.ref_name }}

  # 4. 모바일 (React Native / Expo) 배포
  deploy-mobile:
    needs: validate-core
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: expo/expo-github-action@v8
      - run: pnpm install
      - name: Build EAS App
        run: eas build --platform all --non-interactive
```

## 6. 보안 및 크로스플랫폼 권한 관리

1. **디바이스 로컬 키체인 격리**:
   - 모바일: iOS Keychain 및 Android Keystore 활용 (`expo-secure-store`).
   - 데스크탑: OS 네이티브 자격 증명 관리자 (`keytar` 또는 Rust `keyring` 크레이트).
   - 브라우저: `HttpOnly` 및 `Secure` 속성이 적용된 Better Auth 쿠키 연동.
2. **최소 권한 원칙 (Least Privilege)**:
   - CLI 도구는 사용자 홈 디렉토리(`.kairos/`) 내부의 데이터에만 쓰기 권한 허용.
   - Chrome Extension은 정해진 도메인(삼성, 카카오, 토스 등 공식 채용 사이트)에 대해서만 Content Script 활성화 권한 획득.
