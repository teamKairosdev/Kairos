## 공식 PPT 권장 구성 (8슬라이드)

| 슬라이드 | 내용 | Kairos 적용 |
|----------|------|-------------|
| **1. 타이틀** | 대회명, 트랙명, 팀명, 서비스명, 발표자 | 팀명: HSL, 서비스명: Kairos |
| **2. 서비스 개요 및 핵심 가치** | 한 줄 소개, 핵심 가치와 목적 | "커리어의 총체적 추적, 종합적 활용 및 관리를 지원하는 종합 경력개발 에이전트 서비스 플랫폼" |
| **3. 문제 배경 및 타깃 사용자** | 페르소나, Pain Point | 고등학생/대학생 취업준비생 → 정보 과부하, 피드백 부재, 데이터 분산 |
| **4. 서비스 주요 기능** | 3가지 이상 핵심 기능 | 이력서 AI 고도화 / 모의면접 SSE / ATS 매칭 / pgvector 검색 / 휴머나이저 |
| **5. 사용자 이용 흐름** | 회원가입→문제해결까지 UI/UX 흐름 도식화 | 가입→프로필→이력서업로드→면접→ATS→피드백→SNS공유 |
| **6. AI·SW 활용 기술 및 서비스 구조** | 백/프론트 구조, AI API 연계, 데이터 아키텍처 | Nuxt 4 + AI SDK v7 + pgvector + Better Auth + SSE + PWA |
| **7. 프로토타입 시연** | 화면 캡처/GIF + **실시간 라이브 데모** | 실제 브라우저로 이력서 업로드→면접→ATS 전 과정 시연 |
| **8. 구현 범위 및 보완 계획** | 완료/미완료 기능, 제약 사항, 향후 계획 | Phase 0-8 완료. 남은 과제: 테스트, 모니터링, CI/CD, Electron |

## 발표 전략 핵심

### 기술구현 및 완성도(40점) 공략
- **있는 기능을 완벽하게 보여줘라.** 새로운 기능을 만드느라 기존 기능이 불안정해지면 역효과.
- 시연 시나리오를 **사전에 3회 이상 리허설** — 네트워크/API 장애 대비 목업 준비.
- "미완성 기능"은 솔직히 밝히고 보완 계획을 구체적으로 제시 (8번 슬라이드).

### 창의성(20점) 공략
- "AI 자소서 첨삭"이라는 오해를 **발표 첫 30초 안에 차단**하라.
- Notion/Obsidian + Threads/X + AI Agent의 융합이라는 독창성을 강조.
- 기존 서비스(자소설닷컴, ChatGPT)와의 차별점을 표로 명확히 비교.

### 문제 정의(15점) + 기대 효과(15점) 공략
- 문제는 **구체적일수록 좋다.** "취업준비생은..." (X) → "경기도 고등학생 A군은 자소서를 10군데 제출했지만 피드백이 없고 내 위치를 모른다" (O)
- 해결 후 변화: "Kairos 사용 후 A군은 자신의 강약점을 파악하고 3개월 만에 면접 합격률 2배 향상"

### 발표(10점) 공략
- 기술 용어 자제, 청중(고등학생+대학생+교수+심사위원)을 고려한 쉬운 언어.
- 시연 중 "이 부분이 신기하죠?" → 청중 반응 유도.
- 질의응답 대비: "AI 환각 문제는 어떻게?" → "pgvector로 사실 기반 검증, 사용자 피드백 루프"
